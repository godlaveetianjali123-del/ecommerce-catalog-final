A modern **E-Commerce Catalog web application** designed to provide a smooth and engaging online shopping experience. The project focuses on clean UI, responsive design, intuitive navigation, and essential e-commerce functionality.

## 🌟 About The Project

**E-Commerce Catalog** is a responsive frontend web application where users can explore products, search through the catalog, view detailed product information, manage their shopping cart, and proceed through the checkout experience.

The project was developed to demonstrate practical skills in **React.js, modern frontend development, component-based architecture, state management, routing, and responsive web design**.

The interface is designed to be simple, clean, and easy to navigate across different screen sizes.

---

## 🚀 Key Features

### 🏠 Home Experience

A welcoming home page that provides users with an easy starting point for exploring the store.

### 🛍️ Product Catalog

Browse available products through a structured and user-friendly product catalog.

### 🔎 Product Search

Search functionality allows users to quickly find products within the catalog.

### 📦 Product Details

Users can open individual products to view more information before adding them to their cart.

### 🛒 Shopping Cart

Users can:

* Add products to the cart
* Increase product quantities
* Decrease product quantities
* Remove products
* Review selected items

### 💳 Checkout

A dedicated checkout experience allows users to review their cart before completing the shopping flow.

### 🔐 Authentication Pages

The application includes dedicated:

* Login page
* Registration page
* User profile page

### 📱 Responsive Design

The application is designed to work smoothly across:

**Desktop • Laptop • Tablet • Mobile**

### ❌ 404 Page

A custom Not Found page provides a better experience when users visit an unavailable route.
